
## Power BI Dashboard

An interactive Power BI dashboard built to explore and analyze the movie dataset.

### Dashboard Preview

![Movies Analytics Dashboard](images/Movies_Analytics_Dashboard.jpg)

### Key Features

- Total Movies
- Average IMDb Rating
- Total Directors
- Average Runtime
- Movies by Genre
- Movies by Certificate
- Movies Released by Year
- Highest-Rated Movies
- Top 10 Directors by Movie Count
- Release Year and Genre slicers
- Reset Filters bookmark button

### Tools Used

- Power BI Desktop
- Power Query
- DAX
- Microsoft Excel / CSV

### Project Files

- `powerbi/Movies_Analytics_Dashboard.pbix` - Power BI report
- `images/Movies_Analytics_Dashboard.jpg` - Dashboard screenshot

### How to View

1. Download the `.pbix` file.
2. Open it using Power BI Desktop.
3. Explore the dashboard using the slicers.
